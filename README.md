# AstroGuidance

A Next.js product that turns a birth date, time, and place into a natal chart, a written reading, and downloadable report pages.

The app geocodes the birth place, calculates the chart, and renders a wheel plus report sections. Signed-in users can save charts, ask a follow-up question, and buy a report. Checkout is wired to Iyzico. Account, privacy, refund, and distance-sales pages are included.

## Stack

Next.js, React, TypeScript, Tailwind CSS, Iyzico

## Run

```bash
npm install
npm run dev
```

Copy `.env.example` to `.env` and fill in the keys the app expects. Node 20.
